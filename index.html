Mit dem privaten Stand verbinden

Diese Seite ist öffentlich und enthält keine Chat-Inhalte. Sie liest stand.json aus dem privaten Repo und schreibt Diskussionen sowie den Wunsch „Neue Vorschläge“ nach gespraeche.json — mit deinem eigenen GitHub-Token. Das Token bleibt in diesem Browser und geht nur an api.github.com. Nichts geht an WhatsApp.

  1. Fine-grained Token anlegen
  2. Repository access: Only select repositories → privates Inhalts-Repo
  3. Permissions → Repository → Contents: Read and write. Sonst nichts. Nur das private Repo.
  4. Token hier einfügen und verbinden.
